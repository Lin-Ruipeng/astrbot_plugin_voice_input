# 只暴露输入模态，不替使用者决定回复方式

AstrBot 预处理阶段会把语音转成文字，并原地替换掉 `Record` 组件，插件层再想判断"这条是不是语音"就得自己找证据。
本插件把这些证据收敛成一个布尔标志 `voice_input`，**不**在插件内部直接要求模型用语音回复。

## Considered Options

- **检测 + 强制语音回复**（最初版本就是这么做的）：装了就能用，但要写死某个 TTS 插件的工具名，且对不想语音回复的人是意外行为。
- **检测 + 可选注入**（选中）：默认只写标志；`inject_prompt` 是显式开关，文案可改。
- **只写文档，让使用者自己实现检测**：把最脏的部分（依赖 `_temporary_local_files` 这类内部结构）丢给每个使用者重复一遍。

## Consequences

- 装完默认"什么都不发生"：必须有人读 `voice_input`，否则看不出插件在工作。README 因此把"快速验证"放在很前面。
- `examples/` 成为产品的一部分，需要和主插件一起维护，否则会过时。
- 好处是同一个标志能同时服务 AstrBot 自带 TTS、第三方音色克隆插件，以及以后任何"按输入模态做事"的插件。
